# Power BI Build Instructions: Retail & Warehouse Sales Analytics

Step-by-step guide to build the complete 2-page interactive dashboard in Power BI Desktop in 15 minutes.

---

## Prerequisites
- [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
- The cleaned dataset: `data/cleaned_sales.csv` (generated by `python/data_cleaning.py`)

---

## Step 1: Import Cleaned Dataset

1. Open Power BI Desktop.
2. Click **Get Data** > **Text/CSV**.
3. Navigate to and select `data/cleaned_sales.csv`.
4. In the preview dialog, ensure:
   - File Origin: `65001: Unicode (UTF-8)`
   - Delimiter: `Comma`
5. Click **Transform Data** to open Power Query Editor.

---

## Step 2: Verify Data Types in Power Query

Verify that the columns have been assigned the following types:
- `YEAR`: Whole Number (`Int64.Type`)
- `MONTH`: Whole Number (`Int64.Type`)
- `SUPPLIER`: Text (`type text`)
- `ITEM CODE`: Text (`type text`)
- `ITEM DESCRIPTION`: Text (`type text`)
- `ITEM TYPE`: Text (`type text`)
- `RETAIL SALES`: Decimal Number (`type number`)
- `RETAIL TRANSFERS`: Decimal Number (`type number`)
- `WAREHOUSE SALES`: Decimal Number (`type number`)

Click **Close & Apply** in the top-left ribbon.

---

## Step 3: Create the Date Dimension Table

1. In the **Modeling** tab, click **New Table**.
2. Paste the DAX code from `PowerBI/Data_Model.md`:
   ```dax
   Calendar = 
   VAR MinYear = MIN ( 'sales'[YEAR] )
   VAR MaxYear = MAX ( 'sales'[YEAR] )
   RETURN
       ADDCOLUMNS (
           CALENDAR ( DATE ( MinYear, 1, 1 ), DATE ( MaxYear, 12, 31 ) ),
           "Year", YEAR ( [Date] ),
           "Month Number", MONTH ( [Date] ),
           "Month Name", FORMAT ( [Date], "MMMM" ),
           "Month Short", FORMAT ( [Date], "MMM" ),
           "Year-Month Key", YEAR ( [Date] ) * 100 + MONTH ( [Date] ),
           "Year-Month", FORMAT ( [Date], "YYYY-MM" )
       )
   ```
3. Right-click the `Calendar` table > **Mark as date table** > select `Date`.
4. In Data View, select column `Month Name` > click **Sort by column** > select `Month Number`.
5. Select column `Year-Month` > click **Sort by column** > select `Year-Month Key`.

---

## Step 4: Establish Model Relationship

1. In table `'sales'`, add a calculated column for the date key:
   ```dax
   DateKey = DATE ( 'sales'[YEAR], 'sales'[MONTH], 1 )
   ```
2. Switch to the **Model View** (left pane).
3. Drag `'sales'[DateKey]` and drop it onto `'Calendar'[Date]`.
4. Confirm Cardinality is **Many to One (*:1)** and Cross filter direction is **Single**.

---

## Step 5: Create Measures Table

1. In the **Home** tab, click **Enter Data**.
2. Name the table `_Measures` and click **Load**.
3. In `_Measures`, create each measure defined in `PowerBI/DAX_Measures.md`:
   - `Total Retail Sales Volume = SUM ( 'sales'[RETAIL SALES] )`
   - `Total Warehouse Sales Volume = SUM ( 'sales'[WAREHOUSE SALES] )`
   - `Total Retail Transfers Volume = SUM ( 'sales'[RETAIL TRANSFERS] )`
   - `Average Retail Sales per Record = AVERAGE ( 'sales'[RETAIL SALES] )`
   - `Retail-to-Warehouse Ratio = DIVIDE ( [Total Retail Sales Volume], [Total Warehouse Sales Volume], BLANK() )`
   - `YoY Retail Sales Growth % = ...`
   - `Cumulative Supplier Retail % = ...`
4. Delete the empty default `Column1` from `_Measures` so the table icon turns into a calculator.

---

## Step 6: Build Page 1 — Executive Overview

1. Rename Page 1 to **Executive Overview**.
2. Set Canvas Background to `#F8F9FA`.
3. Add a **Header**: Text box with text `"Retail & Warehouse Sales Analytics | Executive Overview"`.
4. Add **Slicers**:
   - Slicer 1: `'Calendar'[Year]` (Dropdown or Tiles).
   - Slicer 2: `'Calendar'[Month Short]` (Horizontal tiles).
5. Add **4 KPI Cards** across the top:
   - Card 1: `[Total Retail Sales Volume]` (Display units: Millions).
   - Card 2: `[Total Warehouse Sales Volume]` (Display units: Millions).
   - Card 3: `[Total Retail Transfers Volume]` (Display units: Millions).
   - Card 4: `[Average Retail Sales per Record]` (Value: `#,##0.00`).
6. Add **Line Chart**:
   - X-Axis: `'Calendar'[Year-Month]`.
   - Y-Axis: `[Total Retail Sales Volume]`.
   - Title: "Monthly Retail Sales Movement Volume".
7. Add **Clustered Column Chart**:
   - X-Axis: `'Calendar'[Year]`.
   - Y-Axis: `[Total Retail Sales Volume]`, `[Total Warehouse Sales Volume]`, `[Total Retail Transfers Volume]`.
   - Title: "Yearly Volume by Channel".
8. Add **Clustered Bar Chart (Left Bottom)**:
   - Y-Axis: `'sales'[ITEM TYPE]`.
   - X-Axis: `[Total Retail Sales Volume]`.
   - Title: "Retail Sales Volume by Item Type".
9. Add **Clustered Bar Chart (Right Bottom)**:
   - Y-Axis: `'sales'[SUPPLIER]`.
   - X-Axis: `[Total Retail Sales Volume]`.
   - Visual Filter: Top N = 10 by `[Total Retail Sales Volume]`.
   - Title: "Top 10 Suppliers by Retail Volume".

---

## Step 7: Build Page 2 — Product & Supplier Analysis

1. Add a new page and name it **Product & Supplier Analysis**.
2. Add Slicers: `'Calendar'[Year]`, `'sales'[ITEM TYPE]`, `'sales'[SUPPLIER]`.
3. Add **Clustered Bar Chart (Top Left)**:
   - Y-Axis: `'sales'[ITEM DESCRIPTION]`.
   - X-Axis: `[Total Retail Sales Volume]`.
   - Visual Filter: Top N = 10 by `[Total Retail Sales Volume]`.
   - Title: "Top 10 Products by Retail Volume".
4. Add **Line and Clustered Column Chart (Top Right)**:
   - Shared X-Axis: `'sales'[SUPPLIER]`.
   - Column Y-Axis: `[Total Retail Sales Volume]`.
   - Line Y-Axis: `[Cumulative Supplier Retail %]`.
   - Visual Filter: Top N = 20 by `[Total Retail Sales Volume]`.
   - Title: "Supplier Volume & Pareto Cumulative Contribution".
5. Add **Scatter Chart (Bottom Left)**:
   - Details: `'sales'[SUPPLIER]`.
   - X-Axis: `[Distinct Item Types Count]`.
   - Y-Axis: `[Total Retail Sales Volume]`.
   - Size: `[Total Warehouse Sales Volume]`.
   - Title: "Supplier Catalog Breadth vs Retail Volume".
6. Add **Matrix Table (Bottom Right)**:
   - Rows: `'sales'[ITEM TYPE]`, `'sales'[ITEM DESCRIPTION]`.
   - Values: `[Total Retail Sales Volume]`, `[Total Warehouse Sales Volume]`, `[Retail-to-Warehouse Ratio]`.
   - Title: "Product Volume Matrix".

---

## Step 8: Save & Publish

1. Save report as `Retail_and_Warehouse_Sales_Analytics.pbix`.
2. Test interactive slicers to confirm all cross-filtering and drill-down behaviors work seamlessly.
